# Bar La Plaza

Carta digital de un bar de tapas con navegación por categorías y un formulario
de pedido a domicilio.

**Demo:** [raafaanavrr69.github.io/Portfolio/Carta-bar](https://raafaanavrr69.github.io/Portfolio/Carta-bar/)

## Contenido

- `index.html`: la carta, dividida en entrantes, principales y postres.
- `pedido.html`: formulario de pedido a domicilio con validación HTML.
- `styles.css`: estilos, adaptados a móvil.

## Tecnologías

HTML5 y CSS3.
